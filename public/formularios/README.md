# Carpeta de Formularios Oficiales DSS

Colocá aquí los archivos de formularios en formato PDF (ejemplo: `formulario-afiliacion.pdf`, `solicitud-reembolso.pdf`, etc.).

Al subir archivos PDF a esta carpeta (`public/formularios/`), estarán accesibles públicamente en la URL:
`https://dss.contadores.org.ar/formularios/<nombre-del-archivo>.pdf`
